Med Alliance Program — Email Flows Reference

All 4 partner onboarding email scenarios. Previews use MedVirtual default theme with placeholder data (firstName = "Sarah", companyName = "MedVirtual").

1

Admin Promotes Existing User to Alliance Partner

Existing platform user gets added as an affiliate by an admin

API Endpoint
POST /med-alliance/admin/affiliates
Who Can Trigger
system_admin system_super_admin
Business Scenario
User already has a platform account. Admin creates an AffiliateProfile linked to that user. Email is sent non-blocking — user's account status is unchanged.
Template File
med-alliance-invitation.ts
Subject You're now a MedVirtual Med Alliance Partner — here's what's next
Email Preview
2

Admin Creates New User as Alliance Partner

New user account and affiliate profile created together — user must set a password

API Endpoint
POST /med-alliance/admin/user-and-affiliates
Who Can Trigger
system_admin system_super_admin
Business Scenario
Admin creates a brand-new user with role affiliate and an AffiliateProfile in one operation. User receives an invite link to set their password. Link expires in 48 hours.
Template File
med-alliance-invite-signup.ts
Subject You've been invited to join the MedVirtual Med Alliance Program — activate your account
Email Preview
3

Admin Links New User to Existing Affiliate Profile

AffiliateProfile already exists (e.g. created via HubSpot) — admin invites a user to claim it

API Endpoint
POST /med-alliance/admin/affiliates/:id/invite-user
Who Can Trigger
system_admin system_super_admin
Business Scenario
An AffiliateProfile exists (typically synced from HubSpot as a Growth Partner) but has no linked user. Admin creates a new user with role affiliate and links them. User receives an invite link to set their password. Link expires in 48 hours.
Template File
med-alliance-invite-signup.ts
Subject You've been invited to join the MedVirtual Med Alliance Program — activate your account
Email Preview
4

Organization Admin Self-Joins the Alliance Program

Existing org admin activates their own affiliate status — no invite link needed

API Endpoint
POST /med-alliance/affiliates/join
Who Can Trigger
organization_admin organization_super_admin
Business Scenario
A logged-in organization admin opts into the Med Alliance Program on their own initiative. AffiliateProfile is created with status active immediately — no signup step required. Email confirms enrollment and directs them to the dashboard.
Template File
med-alliance-invitation-for-org-users.ts
Subject Welcome to the Med Alliance Program, Sarah

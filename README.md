## Description

Backend side from MedVirtual system developed in [Nest]

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash

# development / watch mode
$ npm run dev

# production mode
# //Just with CICD in the github action
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

this application there  automatic deploy using github actions.

```bash
$ npm run deploy

```
